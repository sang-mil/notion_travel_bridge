Notion Travel Bridge

Notion 여행 계획 → Gemini 분석 → Google My Maps → Notion 결과 기록

Notion Travel Bridge 사용자 설명서

Notion에 작성한 여행 계획을 가져와 Gemini가 날짜별 장소로 정리하고, Google My Maps에 핀으로 표시한 뒤, 완성된 지도 링크와 재사용 템플릿 링크를 Notion 페이지에 기록하는 Windows용 도구입니다.

1. 사용 전 알아둘 점

  • 각 사용자는 본인의 Notion 통합 토큰과 Gemini API 키를 설정해야 합니다. 패키지에는 실제 키가 들어 있지 않습니다.
  • 인터넷 연결과 Google Chrome이 필요합니다.
  • Google 계정 로그인과 2단계 인증은 브라우저에서 사용자가 직접 처리합니다.
  • Google My Maps의 화면 구성이 바뀌면 CSV 가져오기 중 일부 버튼이나 열을 수동으로 선택해야 할 수 있습니다.
  • 이 도구는 온라인 My Maps 지도를 만듭니다. 오프라인 지도 다운로드는 하지 않습니다.

2. 필요한 프로그램/계정

  1. Windows 10/11
  2. Python 3.10 이상 (Python 3.12 64비트 권장)
  3. Google Chrome
  4. Notion 계정, 여행 계획 페이지와 Notion Internal Integration 토큰
  5. Google AI Studio에서 발급한 Gemini API 키

3. 처음 설치하기

  1. ZIP 파일을 원하는 폴더에 압축 해제합니다.
  2. QuickStart.bat을 더블클릭합니다.
  3. 메뉴에서 1. 최초 설정 / 설치 상태 점검을 선택합니다. 가상환경과 필요한 Python 패키지가 준비됩니다.
  4. .env가 열리면 다음 값을 채우고 저장합니다.
NOTION_TOKEN=본인의_Notion_통합_토큰
NOTION_PAGE_ID=여행_계획_Notion_페이지_URL_또는_ID
NOTION_VERSION=2026-03-11
GEMINI_API_KEY=본인의_Gemini_API_키
GEMINI_MODEL=gemini-2.5-flash

.env는 비밀 설정 파일입니다. API 키를 채팅, 스크린샷 또는 공개 GitHub 저장소에 올리지 마세요. 이 파일은 ZIP에 포함되지 않습니다.

4. Notion 연결 설정

  1. Notion 개발자용 Internal Integration을 만듭니다.
  2. 통합에 페이지 콘텐츠 읽기, 삽입, 수정 권한을 부여합니다.
  3. 여행 계획 페이지에서 해당 통합을 Connections/연결 메뉴를 통해 공유합니다.
  4. NOTION_TOKEN에는 통합 토큰을, NOTION_PAGE_ID에는 페이지 URL 또는 ID를 넣습니다.
  5. Gemini API 키를 GEMINI_API_KEY에 넣습니다.

새 여행을 위해 페이지를 복제했다면 새 페이지도 통합과 공유해야 할 수 있습니다. 권한 메뉴 명칭은 Notion의 언어와 UI 버전에 따라 다를 수 있습니다.

5. 여행 계획은 이렇게 작성하세요

자연어로 적어도 되지만, 날짜·장소 이름·방문 순서를 명확하게 작성하면 결과가 좋아집니다.

여행 제목: 오사카·교토 4박 5일
목적지: 일본 오사카, 교토
여행 기간: 2026-11-10 ~ 2026-11-14
동행자: 성인 2명
여행 스타일: 역사 관광과 맛집, 하루 관광지 3곳 이하
이동·체력 조건: 연속 도보 30분 이내, 계단 최소화, 1시간마다 휴식

1일 차 - 오사카
방문 순서: 오사카성 → 도톤보리 → 신사이바시
꼭 가고 싶은 곳: 오사카성
식사·휴식: 도톤보리에서 점심, 오후 카페 휴식
주의·대체안: 비가 오면 실내 관광지로 변경

여행 제목, 목적지, 기간, 날짜별 장소, 방문 순서, 식사와 휴식, 계단/언덕 회피 등 조건을 구체적으로 작성하세요. 장소가 모호하면 AI가 틀린 장소를 선택할 수 있으므로 정확한 장소명을 적거나 [확인 필요]라고 표시합니다. 추가 예시는 templates/notion_travel_plan_template.md에 있습니다.

6. 전체 실행 순서

  1. QuickStart.bat을 더블클릭합니다.
  2. 처음에는 1. 최초 설정 / 설치 상태 점검을 실행합니다.
  3. 2. Google My Maps 로그인 준비를 선택합니다.
  4. 열린 프로젝트 전용 Chrome에서 Google 로그인을 직접 완료합니다.
  5. 이 전용 Chrome 창을 완전히 닫습니다.
  6. Quick Start에서 3. 전체 실행을 선택합니다.

전체 실행은 아래 순서로 진행됩니다.

  1. Notion에서 원본 일정 가져오기
  2. Gemini로 날짜/장소 구조화
  3. Google My Maps용 CSV 및 지도 링크 생성
  4. Google My Maps에서 지도 생성 또는 갱신
  5. 지도 링크 및 재사용 템플릿 링크를 Notion 페이지에 기록

My Maps 화면 요소를 자동으로 찾지 못하면 브라우저에서 직접 버튼을 누르거나 열을 선택하라는 안내가 나올 수 있습니다. 안내된 브라우저 작업을 끝낸 뒤 PowerShell 창에서 Enter를 누릅니다. 브라우저에서 Enter를 누르라는 의미가 아닙니다.

기존 지도 데이터 교체를 요청받으면 화면과 지도 URL이 맞는지 확인하세요. 프로그램이 REPLACE 입력을 요청할 수 있습니다.

7. Quick Start 메뉴

메뉴설명
1. 최초 설정 / 설치 상태 점검Python, 라이브러리, Chrome, .env 설정 확인
2. Google My Maps 로그인 준비프로젝트 전용 Chrome을 열어 직접 로그인
3. 전체 실행Notion → Gemini → My Maps → Notion 전체 과정
4. 기존 지도 결과만 Notion에 기록기존 지도 URL과 결과를 Notion에 기록
5. .env 설정 열기API 키와 페이지 ID 수정
6. 출력 폴더 열기중간 산출물 및 디버그 스크린샷 확인
7. 사용자 설명서 열기이 설명서를 엽니다

8. 완료 결과 확인

전체 실행이 완료되면 원래 여행 계획 페이지에 Google My Maps 지도 링크와 간단한 메타데이터, 재사용 템플릿 링크가 추가/갱신됩니다. 지도를 열어 핀을 클릭하고 장소 이름과 위치가 맞는지 확인하세요. 핀 이름이 지도에 항상 노출되지 않더라도 클릭한 정보창에 제목이 올바르면 정상일 수 있습니다.

9. 다음 여행 시작하기

  1. Notion에 만들어진 여행 계획 템플릿 페이지를 복제합니다.
  2. 새 페이지 안의 예시 문구를 실제 여행 계획으로 변경합니다.
  3. .env의 NOTION_PAGE_ID를 새 여행 페이지의 URL 또는 ID로 변경합니다.
  4. 새 페이지도 Notion 통합과 공유되어 있는지 확인합니다.
  5. QuickStart.bat → 3. 전체 실행을 선택합니다.

NOTION_PAGE_ID를 변경하지 않으면 이전 여행 페이지를 다시 처리합니다.

10. 결과 파일

  • output/itinerary_text.txt: Notion에서 가져온 원문
  • output/itinerary.json: Gemini가 구조화한 일정
  • output/map_import.csv: Google My Maps 가져오기 CSV
  • output/google_maps_links.md: Google 지도 검색/경로 링크 모음
  • output/mymaps_config.json: My Maps URL 및 마지막 가져오기 상태
  • output/notion_sync_config.json: Notion 동기화 블록/템플릿 기록 정보
  • output/browser_debug/: 자동화 문제 진단 스크린샷

개인 일정이나 링크가 포함될 수 있으므로 출력 파일을 공유하기 전에 내용을 확인하세요.

11. 문제 해결

Notion 401 오류

토큰이 맞는지 확인하고, .env에 공백이나 예시용 값이 남아 있지 않은지 확인합니다.

Notion 403 또는 404 오류

대상 페이지가 통합과 공유되어 있는지, 통합에 읽기/삽입/수정 권한이 있는지, 페이지 ID가 맞는지 확인합니다.

Gemini 키/할당량 오류

GEMINI_API_KEY, GEMINI_MODEL, 인터넷 연결 및 본인 계정의 API 사용량/제한을 확인합니다.

Google 로그인이 반복됨

자동화 브라우저에서 로그인을 반복하지 마세요. 메뉴 2에서 열린 전용 Chrome에서 직접 로그인하고, 전용 창을 완전히 닫은 뒤 메뉴 3을 실행합니다.

Map search query 또는 Place 열 자동 선택 실패

브라우저 화면에서 Map search query를 위치 지정 열로 선택하고 계속을 누릅니다. 다음 화면에서 Place를 핀 제목 열로 선택하고 완료를 누릅니다. 핀이 표시되는지 확인한 뒤 PowerShell이 Enter를 기다릴 때만 Enter를 누릅니다.

지도 핀만 보이고 이름이 지도 위에 없음

핀을 클릭해 정보창 제목을 확인합니다. 지도 위 라벨은 별도로 설정해야 할 수 있습니다.

같은 CSV라며 업로드를 건너뜀

같은 CSV를 중복으로 업로드하지 않도록 건너뛴 것입니다. 기존 지도 URL이 올바른지 확인하세요. 새 지도를 만들고 싶다면 publish_mymaps.py --new-map을 별도로 실행할 수 있습니다.

My Maps UI 요소 탐지 오류

오류에 표시된 output/browser_debug/ 스크린샷을 확인하고, 브라우저에서 해당 단계를 수동으로 완료합니다. Google My Maps 웹 UI가 바뀌면 자동화 선택자를 업데이트해야 할 수 있습니다.

오프라인 지도

이 도구는 온라인 My Maps를 생성합니다. Google Maps 앱에서 오프라인 지도를 별도로 내려받아야 하며, My Maps 사용자 지정 레이어가 오프라인에서도 동일하게 표시된다고 보장하지 않습니다.

12. 보안 및 정확성

  • .env 안의 API 키/토큰을 공유하지 마세요.
  • Google 로그인을 브라우저에서 직접 수행합니다. 프로그램에 비밀번호나 인증 코드를 입력하지 않습니다.
  • .env, .mymaps_browser_profile, .venv, 개인 출력 파일은 공개 저장소에 올리지 마세요.
  • 지도 위치 매칭이 틀릴 수 있습니다. 실제 여행 전에 장소명, 핀 위치, 영업시간, 휴무일, 예약, 이동 경로를 확인하세요.
